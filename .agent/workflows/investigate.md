# 调查工作流

输入：需要回答的问题、调查范围，以及可用的源码、记录或资料。

1. 将问题拆成需要确认的事实。涉及实现时，通过 [代码参考](../code-map.md) 找到对应源码与测试；涉及执行状态时检查实际记录。
2. 沿调用链或来源核对证据。需要外部事实时查阅相应的一手资料，将已确认事实、推断和未知项分开记录。
3. 按问题直接给出结论与证据位置；未确认项说明缺少什么证据。用户同时要求设计或修改时，将发现传给 [任务路由](../task-router.md) 选择的后续工作流。

完成条件：用户问题的各项均有结论或明确的证据缺口；实现状态有源码或执行结果支撑。调查本身不扩大为未请求的功能修改。
