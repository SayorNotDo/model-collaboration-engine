# 外部榜单接入验收

日期：2026-09-16。对应[设计](external-ranking-design.md)与[使用指南](../rankings.md)。

## 实现

- Python `load_rankings` 导入 UTF-8 JSON/CSV，显式映射模型及版本，返回规范配置和未映射/缺失名次报告；CLI 只写新文件。
- 初次交付中，Rust 校验可选 `routing.rankings`，先执行硬约束，再加有界榜单贡献；路由快照版本 3 固定来源、版本、时间、配置摘要及逐候选解析结果。
- 后续[任务适配路由](task-fit-routing-contract.md)将新任务升级为 schema 4/task-fit-v1：榜单只裁决主评分完全相同的候选，版本 1..3 保留当时的复算语义。SQLite schema 仍为 2。
- 已更新领域说明、README、配置指南及架构/反馈图。示例数据均为合成数据，未修改用户运行配置或真实账务数据。
